Reference / Algorithms

Cipher guide

What each option does and where it fits in this assignment.

Vigenère — DD1

A polyalphabetic substitution cipher. Each plaintext letter is shifted by the matching letter of a repeating keyword. It preserves spacing and punctuation but is not secure by modern standards.

Envelope: DD1:<ciphertext>

AES-256-GCM — DD2

A modern symmetric authenticated-encryption mode. AES uses a 256-bit key; GCM also checks integrity, so modified data or a wrong key causes authentication failure.

Envelope: DD2.<MessageID>.<nonce hex>.<tag hex>.<base64url ciphertext>

ROT13 — additional cipher

A Caesar-style rotation that moves each Latin letter 13 places. Applying it twice restores the original text. It is useful as a simple comparison cipher, not for protecting sensitive data.

Validation / Notes

Processing checks

Key validation

Vigenère requires at least one A–Z key letter. AES requires exactly 32 bytes represented as 64 hexadecimal characters.

AES authentication

Decryption verifies the GCM authentication tag. If the key, nonce, tag, ciphertext or AAD is wrong, the plaintext is not returned.

Record integrity

CSV downloads keep the original columns and MessageIDs, then append processed text, cipher and per-row status fields.
